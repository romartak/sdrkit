# sdrkit
Portable tinySA-style spectrum analyzer, radio receiver and decoder built on a Raspberry Pi Zero 2 W + RTL-SDR, controlled from your phone over WiFi. Listen to FM/AM/digital voice (DMR, P25, D-Star, M17), decode CTCSS/DCS, pagers, APRS, sensors and aircraft, record and scan. One-command install and updates.
